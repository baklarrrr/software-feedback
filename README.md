[Browse existing feedback](https://github.com/baklarrrr/software-feedback/issues) before opening a new report. A GitHub account is required to submit or comment; you can browse without signing in.

## Before posting

Issues and comments are public, including your GitHub username. Do not include personal or client information, email addresses, credentials, tokens, private file paths, or confidential projects. Use a small example you are allowed to share. Do not attach unreviewed logs, screenshots, or files.

For a suspected vulnerability, use [private security reporting](https://github.com/baklarrrr/software-feedback/security/advisories/new), not a public issue. See [SECURITY.md](SECURITY.md).

## What happens next

Reports can be reviewed, clarified, grouped, or closed as duplicates. A report is not a commitment to a fix, a release date, or a particular response time. Follow its issue for updates. Please keep discussion specific, respectful, and relevant to the software.

This hub contains feedback forms and guidance. Application source, installers, and private project records are not hosted here. Each application retains the terms and third-party notices linked on its website.

See [CONTRIBUTING.md](CONTRIBUTING.md) for a useful report and safe posting guidance.
